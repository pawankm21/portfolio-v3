I built and maintained the official IIIT Bhubaneswar placement website with a Next.js frontend, a Node.js backend, and PostgreSQL.

## Keeping placement data up to date

Placement data came from Excel files. The update workflow parsed those files, transformed the data, and saved it in PostgreSQL, removing the need to enter the same information again by hand.

## The stack

Next.js for the frontend, Node.js for the backend, and PostgreSQL for storage.
