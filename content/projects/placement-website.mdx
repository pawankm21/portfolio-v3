I built and maintained the official IIIT Bhubaneswar placement website with a Next.js frontend, a Node.js backend, and PostgreSQL.

## Keeping placement data up to date

The update workflow extracted and parsed Excel files, transformed the data, and stored it in a relational database. This automated placement data updates rather than requiring the same information to be entered again by hand.

## The stack

- **Next.js** for the frontend.
- **Node.js** for the backend.
- **PostgreSQL** for relational storage.
