At Informatica, I owned end-to-end full-stack development of For’CE, a log-analysis copilot using Java Spring Boot, React, and Azure OpenAI.

## From logs to useful context

The work included microservices for log aggregation and analysis, with Elasticsearch supporting search and retrieval at scale. I also created an MCP server for generative AI model integration and intelligent log analysis.

## Reproducing the problem

The repro-copilot feature automated customer environment replication, improving customer troubleshooting efficiency by **50%**.

The copilot achieved an **84% adoption rate** and analyzed **20,000+ support cases**, as recorded in my resume.

## Keeping changes compatible

I designed and implemented an OpenSearch index versioning strategy to support backward compatibility and zero-downtime migrations.

Earlier work on the log analyzer included a reusable React component library and CI/CD pipelines using Jenkins and Ansible.
