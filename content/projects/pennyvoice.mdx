PennyVoice is a work-in-progress expense tracker. Speak or type an expense, review it, and save it to a local ledger.

## What I’m building

The app brings spending, budgets, debts, and repayments into one place. Entries save to IndexedDB first, so a backend outage does not block local ledger activity. Browser speech recognition may still need an internet connection.

Optional accounts add synchronization with a Spring Boot and PostgreSQL backend. Spending analysis includes monthly totals, weekly trends, and larger expenses.

## The stack

React, TypeScript, a progressive web app frontend, IndexedDB, Spring Boot, and PostgreSQL.

The project is still evolving and is not publicly hosted.
