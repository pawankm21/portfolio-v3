PennyVoice is a work-in-progress expense tracker. Speak or type an expense, review it, and save it to a local ledger.

## The ledger

The ledger tracks spending, budgets, debts, and repayments. Entries save to IndexedDB first, so you can keep using it during a backend outage. Browser speech recognition may still need an internet connection.

With an account, entries can sync through a Spring Boot and PostgreSQL backend. Spending analysis shows monthly totals, weekly trends, and larger expenses.

## The stack

React, TypeScript, a progressive web app frontend, IndexedDB, Spring Boot, and PostgreSQL.

There’s no public deployment yet.
